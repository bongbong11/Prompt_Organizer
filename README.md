# 접어 (Prompt Organizer)

SillyTavern **Chat Completion Prompt Manager를 보기 편하게 정리하는 UI 전용 확장**입니다.

프롬프트 사이에 화면용 구분선을 넣고, 원하는 프롬프트 묶음을 접거나 펼칠 수 있습니다.  
실제 프롬프트 내용·순서·Role·Depth·활성화 상태는 변경하지 않습니다.

## 주요 기능

- 화면에만 보이는 **구분선** 추가
- 구분선 이름과 위치 지정
- 구분선마다 원하는 프롬프트를 묶어서 **접기 / 펼치기**
- 현재 활성화된 OpenAI/Chat Completion 프리셋을 자동으로 따라감
- 프리셋별 구분선 설정 개별 저장
- 저장된 구분선 수정 / 삭제
- 저장된 구분선 **복제**
- 프롬프트 이름 **검색**
- 프롬프트 **전체 선택 / 전체 해제**
- PC에서 **Shift + 클릭 연속 선택**
- 모바일에서도 쓸 수 있는 **시작 ~ 끝 범위 선택**
- 저장된 구분선 **모두 접기 / 모두 펼치기**
- 현재 프리셋의 구분선 설정을 **다른 프리셋으로 통째로 복사**
- SillyTavern 테마 CSS 변수 연동
- 모바일 대응
- 채팅 입력창 옆 종이접기 아이콘
- 마법봉(Extensions) 메뉴의 **접어** 항목
- 확장 설정의 **확장 사용** 토글

---

## 설치

SillyTavern의 확장 설치 화면에서 아래 저장소 주소를 입력합니다.

```
https://github.com/bongbong11/Prompt_Organizer
```

설치 또는 업데이트 후 SillyTavern을 새로고침합니다.

---

# 사용 방법

## 1. 접어 열기

다음 중 하나로 열 수 있습니다.

- 채팅 입력창 옆 **종이접기 아이콘**
- SillyTavern의 마법봉 / Extensions 메뉴 → **접어**

상단에는 현재 적용 중인 Chat Completion 프리셋 이름이 표시됩니다.

> 접어 내부에서 프리셋을 따로 바꾸는 방식이 아닙니다.  
> SillyTavern에서 현재 선택된 프리셋을 자동으로 따라갑니다.

---

## 2. 새 구분선 만들기

**새 구분선** 탭에서 설정합니다.

### 구분선 이름

Prompt Manager에 표시될 화면용 제목입니다.

예:

- CORE
- STYLE
- RELATIONSHIP
- AUTHOR NOTES

### 기준 프롬프트

구분선을 어느 프롬프트를 기준으로 둘지 선택합니다.

### 위치

- **앞에**: 기준 프롬프트 바로 앞에 구분선 표시
- **뒤에**: 기준 프롬프트 바로 뒤에 구분선 표시

### 접기 가능

켜면 Prompt Manager에서 구분선 왼쪽 화살표로 해당 묶음을 접거나 펼칠 수 있습니다.

끄면 단순한 시각적 구분선으로만 사용됩니다.

---

# 접을 프롬프트 고르기

구분선 아래에서 숨기고 싶은 프롬프트를 선택합니다.

여러 개를 빠르게 선택할 수 있도록 다음 기능이 있습니다.

## 검색

**프롬프트 검색...** 칸에 이름 일부를 입력하면 목록이 즉시 필터링됩니다.

예:

```
style
relationship
author
```

처럼 일부 단어만 입력해도 됩니다.

## 전체 선택

현재 화면에 보이는 프롬프트를 한꺼번에 선택합니다.

- 검색하지 않은 상태 → 전체 프롬프트 선택
- 검색 중인 상태 → **검색 결과로 보이는 프롬프트만 선택**

## 전체 해제

현재 검색 상태와 관계없이 선택된 프롬프트를 전부 해제합니다.

## Shift + 클릭 연속 선택 (PC)

1. 첫 번째 프롬프트 체크
2. **Shift**를 누른 채 마지막 프롬프트 클릭
3. 그 사이 프롬프트가 한꺼번에 같은 상태로 선택됩니다.

프롬프트가 길게 이어진 구간을 빠르게 묶을 때 편합니다.

## 시작 ~ 끝 범위 선택

모바일이나 Shift 선택이 불편할 때 사용합니다.

1. 왼쪽에서 **시작 프롬프트** 선택
2. 오른쪽에서 **끝 프롬프트** 선택
3. **이 범위만 선택** 클릭

그러면 두 프롬프트 사이의 항목이 전부 선택되고, 범위 밖 선택은 해제됩니다.

예:

```
STYLE
↓
NPC
↓
RELATIONSHIP
↓
SCENE
```

시작을 STYLE, 끝을 SCENE으로 정하면 그 사이가 한 번에 선택됩니다.

---

## 3. 구분선 저장

설정을 마친 뒤 **구분선 저장**을 누릅니다.

저장하면 자동으로 **저장된 구분선** 탭으로 이동합니다.

설정은 현재 활성 프리셋에만 저장됩니다.

---

# 저장된 구분선 관리

## 구분선 펼쳐서 수정

저장된 구분선의 이름 또는 연필 아이콘을 누르면 편집 영역이 열립니다.

다음 항목을 바로 바꿀 수 있습니다.

- 구분선 이름
- 기준 프롬프트
- 앞 / 뒤 위치
- 접기 가능 여부
- 접을 프롬프트 목록

변경 사항은 **자동 저장**됩니다.

별도의 저장 버튼을 다시 누를 필요가 없습니다.

---

## 구분선 복제

편집 영역 아래의 **이 구분선 복제**를 누르면 같은 설정을 가진 복사본이 바로 아래에 생성됩니다.

복사본 이름에는 `복사본`이 붙고, 이후 원하는 부분만 수정하면 됩니다.

비슷한 프롬프트 묶음을 여러 개 만들 때 편합니다.

---

## 구분선 삭제

휴지통 아이콘을 누르면 확인 후 해당 구분선을 삭제합니다.

삭제되는 것은 접어의 화면 정리 설정뿐이며, 실제 Prompt Manager 프롬프트는 삭제되지 않습니다.

---

# 모두 접기 / 모두 펼치기

**저장된 구분선** 탭 상단에서 사용할 수 있습니다.

### 모두 접기

`접기 가능`이 켜진 모든 구분선을 접힌 상태로 만듭니다.

### 모두 펼치기

`접기 가능`이 켜진 모든 구분선을 펼친 상태로 만듭니다.

이 상태도 저장되므로 Prompt Manager가 다시 렌더링되어도 유지됩니다.

---

# 다른 프리셋으로 설정 복사

**저장된 구분선 → 다른 프리셋으로 복사**를 누릅니다.

대상 프리셋의 **이름을 정확히 입력**하면 현재 프리셋의 구분선 구성을 통째로 복사합니다.

이미 접어 설정이 저장된 프리셋 이름은 입력창 안내에 함께 표시될 수 있습니다.

### 대상 프리셋에 기존 설정이 있는 경우

이미 구분선이 저장되어 있으면 덮어쓸지 한 번 더 확인합니다.

확인하면:

- 대상 프리셋의 기존 접어 구분선 설정 삭제
- 현재 프리셋의 구분선 설정 복사
- 복사된 구분선은 펼쳐진 상태로 시작

실제 SillyTavern 프리셋 내용 자체를 복사하거나 수정하는 기능은 아닙니다.

---

# Prompt Manager에서 접기 / 펼치기

접기 설정이 적용된 Prompt Manager에는 구분선이 표시됩니다.

접기 가능한 구분선 왼쪽의 화살표를 누르면 해당 구분선에 지정한 프롬프트만 화면에서 숨겨집니다.

다시 누르면 원래대로 표시됩니다.

> 숨겨진 프롬프트도 모델에는 정상적으로 전달됩니다.  
> **화면에서만 접히는 기능**입니다.

---

# 프리셋을 바꾸면 어떻게 되나요?

SillyTavern에서 Chat Completion 프리셋을 변경하면 접어도 새 프리셋을 자동으로 감지합니다.

- 기존 관리 창은 닫힘
- 새 프리셋에 저장된 구분선 설정을 불러옴
- Prompt Manager 화면을 새 설정으로 다시 정리

각 프리셋 설정은 서로 독립적으로 저장됩니다.

---

# 확장 끄기

SillyTavern:

**확장 설정 → 접어 → 확장 사용**

토글을 끄면:

- Prompt Manager의 접어 구분선 제거
- 접혀 있던 프롬프트 모두 다시 표시
- 채팅 입력창 아이콘 제거
- 마법봉 메뉴의 접어 항목 제거

저장된 구분선 설정은 삭제되지 않습니다.

다시 켜면 그대로 복원됩니다.

---

# 저장되는 데이터

접어는 `extensionSettings.promptOrganizer`에 다음 정보만 저장합니다.

- 프리셋별 구분선
- 구분선 이름
- 구분선 위치
- 접을 프롬프트 ID 목록
- 접기 가능 여부
- 접힘 / 펼침 상태
- 확장 사용 여부

실제 프롬프트 내용은 저장하거나 복사하지 않습니다.

---

# 안전 범위

접어는 Prompt Manager의 **화면 표시만 정리**합니다.

다음 항목은 변경하지 않습니다.

- 프롬프트 내용
- 프롬프트 순서
- Role
- Depth
- Order / Position
- 프롬프트 ON / OFF 상태
- 프리셋 내용
- 프리셋 저장 파일
- 생성 직전 API 전송 배열
- 모델에 전달되는 메시지 구조

따라서 구분선을 넣거나 프롬프트를 접어도 실제 생성 결과의 프롬프트 구성에는 영향을 주지 않습니다.

---

# 팁

프롬프트가 많다면 하나씩 체크하기보다 다음 순서가 가장 빠릅니다.

1. 구분선 이름 입력
2. 구분선을 둘 기준 프롬프트 선택
3. **시작 ~ 끝 범위 선택**으로 큰 구간 잡기
4. 필요하면 검색으로 몇 개만 추가/해제
5. 저장

PC에서는 연속된 짧은 구간을 잡을 때 **Shift + 클릭**이 더 빠릅니다.

비슷한 그룹이 필요하면 처음부터 다시 만들지 말고 **이 구분선 복제**를 사용하면 됩니다.

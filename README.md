# Prompt Organizer

SillyTavern Prompt Manager를 정리하기 위한 UI 확장입니다.

## 기능

- 모델에 주입되지 않는 화면 전용 구분선
- 특정 프롬프트 앞/뒤에 구분선 배치
- 구분선별 프롬프트 선택
- 접기/펼치기 가능한 그룹
- 선택한 프롬프트를 하나의 Chat Completion 메시지로 병합
- 병합 역할을 시스템 / 사용자 / 어시스턴트 중 선택
- 프리셋별 그룹 설정 저장
- SillyTavern 테마 CSS 변수 연동
- 한글 설정 UI

## 설치

SillyTavern의 확장 설치 화면에서 이 저장소 URL을 사용합니다.

`https://github.com/bongbong11/Prompt_Organizer`

## 사용

확장 설정의 **프롬프트 정리**에서 `구분선 추가`를 누른 뒤 이름, 위치, 포함할 프롬프트를 선택합니다.

`접기 가능한 구분선`을 켜면 Prompt Manager에서 해당 구분선 아래의 선택된 프롬프트를 접고 펼칠 수 있습니다. 접기는 화면 표시만 바꾸며 프롬프트 활성화 상태에는 영향을 주지 않습니다.

`하나의 메시지로 묶어서 전송`을 켜면 선택한 활성 프롬프트를 최종 Chat Completion 요청에서 하나의 메시지로 합치고, 그룹에서 지정한 역할을 사용합니다.

## 주의

병합 기능은 최종 Chat Completion 배열에서 현재 프롬프트의 준비된 텍스트와 정확히 일치하는 메시지를 대상으로 합니다. SillyTavern 또는 다른 확장이 프롬프트 내용을 생성 직전에 추가 변형하는 경우 해당 항목은 안전을 위해 병합하지 않습니다. 일치하는 항목이 두 개 미만이면 원래 전송 구조를 유지합니다.
